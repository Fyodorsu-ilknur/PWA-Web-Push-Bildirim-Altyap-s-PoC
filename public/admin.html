⚙️ Web Push Mimarisi

1. İstemci VAPID Public Key ile tarayıcının yerel PushManager servisine abone olur.

2. Üretilen benzersiz Endpoint & Cryptographic Keys (p256dh, auth) sunucumuza iletilir.

3. Sunucu web-push kütüphanesiyle VAPID Private Key kullanarak şifreli JWT imzalar ve Google FCM / Apple APNs push sunucularına gönderir.

4. İstemci cihaz internete bağlı olduğu anda işletim sistemi düzeyinde Service Worker uyandırılır ve bildirim ekrana yansıtılır.
